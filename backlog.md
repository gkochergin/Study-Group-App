# Product Backlog

Stories are ordered by priority. The top 5 are in Sprint 1 and include acceptance criteria.

## 1. Create a Study Group (Sprint 1)

As a creator, I want to create a study group tied to a specific class (course code and section), so that students in that class can find and join it.

**Acceptance Criteria:**
- The creator can create the group.
- The creator can add details such as meeting time, course number, and description.

## 2. Join a Study Group (Sprint 1)

As a participant, I want to join or request to join a study group, so that I can take part in its sessions.

**Acceptance Criteria:**
- The user can press Join to see the group's information (meeting location, time, etc.).
- The user can do what other members can after joining, such as commenting.

## 3. Search and Browse Groups (Sprint 1)

As a participant, I want to search and browse study groups by class, so that I can find a group for the course I need help with.

**Acceptance Criteria:**
- The user can enter a class name into the search bar.
- The user can see the correct study group for that class.

## 4. Share a Study Group (Sprint 1)

As a participant, I want to share a study group with classmates via a link or in-app invite, so that friends in the same class can join too.

**Acceptance Criteria:**
- The user can open a unique link that goes directly to the group.
- The user can share the group from the app to people in their contacts.

## 5. Comment on a Study Group (Sprint 1)

As a participant, I want to comment on the study group post, so that I can respond to it.

**Acceptance Criteria:**
- The user can comment on posts.
- The user can see comments.

## 6. Notifications

As a participant, I want to receive notifications about upcoming sessions and schedule changes, so that I don't miss a meeting or show up at the wrong time.

## 7. Edit or Cancel a Session

As a group leader, I want to edit or cancel a session and have members notified automatically, so that everyone stays informed without me messaging each person.

## 8. Group Size and Join Requests

As a group leader, I want to set a maximum group size and approve or decline join requests, so that the group stays a manageable size and focused.

## 9. Add to Calendar

As a participant, I want to add study sessions to my personal calendar, so that I can plan around my other classes and commitments.

## 10. Shared Study Materials

As a participant, I want to upload and access shared study materials (notes, practice problems, files), so that the group can prepare and review together.

## 11. Group Chat

As a participant, I want to message other members in a group chat, so that we can coordinate, ask questions, and share updates between sessions.
