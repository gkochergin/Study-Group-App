# Sprint 1 Plan

**Sprint Goal:** A student can create a study group for a class, and another student can search for that class, find the group, join it, share its link, and comment on it. The user will also be presented with the information within it, such as meeting times, locations, and any other user submissions made by its members.

## Story 1: Create a Study Group

As a creator, I want to create a study group tied to a specific class (course code and section), so that students in that class can find and join it.

**Acceptance Criteria:**
- The creator can create the group.
- The creator can add details such as meeting time, course number, and description.
  
## Story 2: Join a Study Group

As a participant, I want to join or request to join a study group, so that I can take part in its sessions.

**Acceptance Criteria:**
- Pressing Join shows the group's information (meeting location, time, etc.).
- After joining, the user can do what other members can, such as commenting.

## Story 3: 
-Search and Browse Groups - M Austin As a participant, I want to search and browse study groups by class, so that I can find a group for the course I need help with. 
**Acceptance Criteria:** The user can enter a class name into the search bar. The correct study group for that class appears.

  
## Story 4: Share a Study Group

As a participant, I want to share a study group with classmates via a link or in-app invite, so that friends in the same class can join too.

**Acceptance Criteria:**
- The user can open a unique link that goes directly to the group.
- The user can share the group from the app to people in their contacts.

## Story 5: Comment on a Study Group

As a participant, I want to comment on the study group post, so that I can respond to it.

**Acceptance Criteria:**
- The user can comment on posts.
- The user can see comments.
